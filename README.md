# «Твоя спина» — полный статический сайт

Это полная рабочая версия сайта со всеми материалами и контактами.

## Состав

- `index.html` — вся разметка и тексты;
- `style.css` — дизайн, адаптивность и анимации;
- `app.js` и `media.js` — интерактивность, раскрытие услуг и галереи;
- `assets/` — фотографии, сертификаты и локальные шрифты;
- `privacy.html` — политика обработки персональных данных и сведения о browser storage;
- `_headers` — заголовки безопасности для совместимого хостинга;
- `.htaccess` — HTTPS и заголовки безопасности для Apache-хостинга.

## Как открыть

Откройте `index.html` в браузере. Для публикации на GitHub Pages разместите содержимое этой папки в корне выбранной ветки.
